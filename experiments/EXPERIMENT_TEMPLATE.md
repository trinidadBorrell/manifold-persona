# Experiment note template — not a result

Copy this file into a new dated experiment folder. Replace each prompt with an actual answer. Mark any missing detail as missing. Do not present this template as a completed run.

## Question

What will this test teach?

## Expected result

What do you expect to see? What result would change your next decision?

## Cheapest test

Can a cheaper test answer the question? Start with one model and one dataset when useful.

## Mode and reason

Choose de-risk or extended. Give one reason. A short notebook is allowed for de-risk work.

## Model and data

Record exact model and data names, versions, splits, and paths. Record the exact prompt or its path.

## Code and command

Record the code path and version or commit ID. Record the exact command. If no run happened, state that here.

## Config and seed

Record parameters, config path, and random seed. Mark fields that do not apply.

## Raw output paths

Link actual raw output files or state that no output exists. Do not invent paths.

## Examples and errors

Inspect raw examples and errors before a summary score. Record examples, error patterns, and limits.

## Contrary evidence

Record cases or checks that oppose the expected result. Mark checks that were not done.

## Next decision

State what the run taught, the next test or stop decision, and any owner or collaborator feedback still needed.

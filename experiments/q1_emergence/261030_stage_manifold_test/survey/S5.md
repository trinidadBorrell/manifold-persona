## 6. Points that contradict or change the plan

Each point names the source. "Inference" is mine.

**C1. A held-out win for the curved model does not show curvature.** Held-out data explain the same variance as train when both share a smooth process (Shinn Fig. 2c). Good held-out prediction allows made-up latent structure (Dabholkar Fig. 2). Test points take their coordinates from the fit, so train and test error fall together (Gerber §1). On a spherical Gaussian a curve already beats a line (Hastie §2.2, §5.6). Inference: the plan needs a null that passes through the whole fit and score pipeline, as in Hastie §7.2 and Huang §2.1, not only a score gap.

**C2. "Curved" and "smooth continuum" may be the same thing here.** Any smooth process on a continuum gives curved-looking PC paths (Shinn Fig. S1, S2; Diaconis Thm 3.1). Inference: a GP on a line is a curve in high dimension, so a covariance-matched Gaussian surrogate with independent rows rejects "no structure", not "no continuum". Say "structure beyond second moments", as LITERATURE.md already suggests for Karkada.

**C3. Random column halves may favour clumps on a single Gaussian.** Gabriel CV picks k>=2 on one cluster when the halves correlate above 0.5 (Fu Prop 2, Prop 4). The fix is noise sphering plus a random rotation, and the authors call it ad hoc (§5). Inference: residual-stream columns are correlated, so a dimension-split placement test (Jensen §3.1 style) has this risk for clumps. It needs a calibration run on a single Gaussian with the same spectrum. Sphering at n=800, d=4096 needs a rank limit first.

**C4. Whole-role hold-out changes the question.** LITERATURE.md proposes it so that a clump gets no free role mean. Merkle §3.3 shows that leaving out a cluster scores new clusters, and leaving out a unit scores existing clusters, and the two can pick opposite models (§4.1). Fu Prop 1 needs every cluster in train and test. Owen and Perry §4 and §5.2 say features on fewer rows than the hold-out can be missed. Inference: with 20 selected roles (draft S6) "new role" has no population. Cross hold-out of rows and columns (Owen and Perry §3.2; Fu §2.2) is the nearest published way to score a clump model. Fix the target before the run.

**C5. Plug-in test latents are biased in a known direction.** Plug-in estimates understate model differences (Wallach §6.4) and do poorly in document completion (§6.3). Cell-style splitting that uses test data for coordinates is anti-conservative (Neufeld §3.3). Feature splitting is valid (Neufeld §3.4). Inference: the valid form for this design is to place a cell from one set of columns or questions and to score on a disjoint set. Question split inside a role (20 for placement, 20 for score) matches Moran §5.2 and needs no noise law, which count splitting does (§4.2).

**C6. Capacity: use one framework.** Linear-kernel GP-LVM equals PCA (Lawrence §2.3, App. B). Inference: compare RBF with linear kernels in the same code, optimiser and latent treatment, not RBF-GPLVM with sklearn PCA. RBF+linear (Hauberg §3.1) nests both. MAP GP-LVM overfits as Q grows (Titsias §5.2), against Lawrence §7, so a Q sweep with MAP confounds capacity with curvature. Evidence comparison mixes a bound with an exact value (inference; Titsias eq. 20, Wallach §4).

**C7. Rank has no single right value.** BCV picks a risk-optimal rank, which can differ from the true rank: true 50, best 0 at medium signal (Owen and Perry Table 2, §9). Real data gave flat curves (§7.3). Aspect ratio far from 1 hurts both errors (§6.4). Row-hold PCA CV is weak (§1.1), and separate row and column deletion falls with k (§3.1). Variance may have no finite rank (Dabholkar Discussion). Inference: report the whole score-vs-rank curve per checkpoint. Do not pick a rank per checkpoint, because that ties the curvature trend to the rank rule.

**C8. Bootstrap at the score level.** Case resampling understates row variance by a factor near nu (Owen 2007 §3.1); here nu is 40 for roles and 20 for questions (inference). Row-and-column resampling is mildly conservative and triples the cell term (Corollary 1). Its theory needs many rows and columns (§4.3); 20 roles is few. Inference: duplicate rows would break latent fits, so resample per-role and per-question scores, not raw cells.

**C9. The surrogate must carry the design.** White noise is too weak (Shinn Fig. 2c). Clustering splits a true Gaussian (Huang §1). With n<d, sample eigenvalues are biased, and the null can be conservative or anti-conservative (Huang §2.3, Table 1). Inference: match role and question main effects as well as the spectrum, and report sensitivity to the eigenvalue estimate.

**C10. Optimiser failure can look like flatness.** PCA init stuck on the Swiss roll, log likelihood -534 vs -45 (Lawrence §7.2.3). Test latents are multi-modal (§8.1, §7.3.1 used ten restarts). Inference: fix restarts and init for all checkpoints. Report failures per checkpoint. Include a positive control with known curvature.

**C11. With 20 roles, geometry between roles is prior, not data.** Metric away from data goes to zero with RBF and flat with RBF+linear (Hauberg §3.1). Recovery needs density (§3.2). Inference: limit any claim to structure within sampled cells. An RBF fit with short length scale can act like clumps, so fit alone will not separate them.

**C12. Likelihood units.** N1 treats 4096 dimensions as independent (Lawrence §2.5). Inference: log-likelihood gaps will be inflated by correlated dimensions, so report squared error in a fixed basis and rescaled per checkpoint, with likelihood second.

**C13. No curved latent plots as evidence.** Horseshoes, Lissajous paths and arbitrary shapes all arise (Diaconis; Shinn Fig. S1; Chari Fig. 7). Compare invariants, not coordinates, across checkpoints (Hauberg §1).

**C15. Regenerating the latent helps only for unit-specific latents.** Treating latents as parameters picked K=7 for true K=4 (Li Table 4). Integrating the held-out latent fixes this for unit-specific latents, and shared latents stay open (Li §7). Inference: a role latent shared by 40 cells is the open case. Hold out cells of a role and the shared latent keeps information from that role, which is the conditional target of Merkle.

**C16. Permutation null for rank is a poor fit to crossed, correlated data.** Parallel analysis needs permutation-invariant noise and fails to give the right null with correlated noise (Dobriban §7). Strong factors shadow weaker ones (§6.4). Inference: the large role mean and token-frequency directions may shadow weak structure, so remove main effects before any rank test.

**C17. Naive CV error bars are too narrow.** In Bates et al. §1.1, nominal 10% intervals missed 31% of the time, because each point is both train and test (§4.1). There the intervals were too small by a factor near 1.6 (§4.1). CV tracks average error over training sets, not the error of the fitted model (§1, §3). The proofs cover OLS with i.i.d. data. Ridge raises the correlation with the fitted model's error to at most 15% in one test (App. F). Inference: do not put fold-based error bars on the curved-minus-flat score. Use the crossed scheme of C8.

**C14. A cheap direct check exists.** A holdout predictive check rejected PPCA on nonlinear data in 63.2% of runs (Moran §5.5.2). Inference: this tests "flat is adequate" with no GP-LVM and may be a good first de-risk step. It assumes independent held-out draws, so it needs care with crossed cells. C19, C20 and C21 limit this point.

**C18. No ready interval exists for the curved-minus-flat score.** One CV run gives no unbiased variance estimate (Bengio and Grandvalet, through Bates §4.1). Nested CV repairs coverage for one model's error (§5). It used 200 random splits and about 1000 times the fits (§5, §6). An interval for a difference between two models is only anticipated (§6). Dependent data is future work (§6). Inference: nested CV is not a drop-in for restarted GP-LVM fits on crossed cells, so C8 stays and its interval stays approximate. Say "the curved procedure scored better", not "this fitted surface is better" (N19).

**C19. A flat model can pass a split check for the wrong reason.** A single split check is the same as Moran's HPC (Li and Huggins §7). Power goes to 1 only if the model cannot match the statistic's mean (Thm 3.1). If it can match, power depends on the ratio rho, and p-values stay away from 0 and 1 when the model overstates uncertainty (Thm 3.1). Inference: PPCA fits second moments, so a variance or covariance statistic gives little power. C14 needs a statistic beyond second moments, fixed before the run. A pass is not evidence of flatness (N24).

**C20. The calibration proofs do not cover this design.** Moran's proof needs a near-normal diagnostic (eq. 48), a vector theta with a near-normal posterior (eq. 52-53), and independent observed and new data (step after eq. 63). Li and Huggins need the same, with i.i.d. draws (§2.1, A1-A3). Their test size failed at high prior weight (Fig. 6b). Inference: a latent per cell grows with n, and crossed cells are not independent. Calibration must be shown by a run on data with known flat structure. It cannot be cited.

**C21. With 20 roles, more questions may not add role-level power.** A within-group split targets observation-level misfit, and a cross-group split targets group-level misfit (Li and Huggins §4.1, §5.2). §4.2 words this the other way; I follow §4.1 and the simulation in §5.2. With 20 groups fixed, more observations per group may not help find group-level misfit (App. B.3, Fig. B.27a). Inference: 40 questions per role help cell-level checks, and role count limits role-level claims. The divided check wants moderate to large data (§7). At n=800 and k=N^0.49 it gives about 26 folds of about 30 cells (inference, arithmetic only).

**C22. Do not use the ARD-kept dimension as a stage measure.** The same motion data kept 5, 4 or 3 dimensions under three latent priors (Damianou §5.3). Inference: the kept dimension is not a data fact. If reported, hold kernel, prior and init fixed, and show it beside the curve of C7.

**C23. One bound can carry both kernels, which helps C6.** The Psi statistics are closed form for the ARD RBF and the linear kernel (Damianou §3.2, App. B). So a linear and an RBF variational GP-LVM can share code and bound. Inference: this replaces bound vs exact with bound vs bound, but the bound gap may still differ by kernel. Test density is a ratio of bounds with training q(X) held fixed (§4.1, eq. 35, fn 2), and test latents have local minima (§4.1). Inference: score squared error on held-out columns from the predictive mean (§4.1, App. D.1), as C12 says. Tables 1 to 3 list no linear-kernel variational baseline. Inference: this paper gives no held-out evidence for curved over flat.

**C24. Fit cost is low, and the likelihood cannot see column structure.** The bound uses Y only through YY^T, so an n x n matrix can replace n x p (Damianou §3.4). Inference: 800 x 800 is enough for the fit. Inference: the fit does not change under a column rotation, which fits N1 and C12. Inference: only a column split brings column identity back, so the risk in C3 sits in the score step, not in the fit.

**C25. Noise pushed through a frozen map takes the map's shape.** Uniform points in 15 dimensions, passed through a UMAP transform fit on MERFISH data, take on a false structure (Chari, Modality-mixing section; S1 Text Fig. L caption; figure not inspected). Inference: any step that places surrogate points with a frozen fit and then reads shape is unsafe. Refit surrogates from the start, as C1 says. For n points in 2D, the max/min distance ratio is at least sqrt((n-2)/2) (S1 Note Thm 1). Inference: 20 equidistant role means in 2D give a ratio of at least 3, which supports C13.

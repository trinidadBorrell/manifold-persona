## 6. Points that contradict or change the plan

Each point marks what papers state and what is my inference.

**A. The gap holds within this reading.**
- Stated: no paper fits a flat, clump and curved model to a cloud across stages. See the stage coverage table.
- SPINAL does not conflict. Its "curvature" is a word for a path across layers, with no formula and no base value.
- Limit: this strand is not saturated, and Xu forward citations are missing. Do not claim "first".

**B. Fixed layer across stages is at risk. This one changes the plan.**
- Stated: on OLMo-2, post-trained models form instruction digests in similar layer groups, but at different ones from base (Bigoulaeva §5). This is the closest paper to our model family.
- Stated: structure can peak mid-depth and fade (Singh §3). Gurnee reports curvature growing with layer (App. G, reader record).
- Inference: run the test at several layers per checkpoint, or show a layer profile. One fixed layer can show a stage effect that is only a layer shift. This qualifies the `LITERATURE.md` row "Fix layer and token first".

**C. A discrete answer is a serious rival for roles. This one changes the plan.**
- Stated: categorical concepts form polytopes, simplices if freely manipulable (Park 2025). Tree latents reproduce similar structure (Nava). The weekday "ring" behaves as seven discrete states (Gupta).
- Stated: the theory is for final-layer unembeddings, and it has not been tested on roles. Nava reports weaker alignment for internal activations (E.4).
- Inference: 20 selected roles may sit at simplex vertices with question variation around them. The clump model should be expected to do well, and this is a result, not a failure.
- Inference: a curve through 20 role centroids always fits. Gupta and Wurgaft show the spline fit is exact by construction. Evidence must come from held-out roles, not fit quality. This supports the `LITERATURE.md` row on holding out whole roles.

**D. Flat, clump and curved are too few rivals.**
- Stated: a mixture of local subspaces beats pure clusters and global factor analysis on held-out error (Shafran App. D, E).
- Inference: local flat patches can match a GPLVM on a curved sheet, so add a mixture of factor analysers. This is S5's Ghahramani and Hinton anchor, now with an LLM use. A tree rival is optional.

**E. PCA rank must be matched, or the comparison misleads.**
- Stated: Engels' circles sit in flat planes. Six PCs hold 95% of Gurnee's 1-D curve (§2.2). Berdnikov's sphere is linearly readable from three dimensions.
- Inference: PCA with enough components ties a curved model, and this does not show flatness. Compare at matched latent dimension, and report held-out error against dimension. The curved claim is "fewer latents for the same error". This extends the "sweep rank" row in `LITERATURE.md`.

**F. The RBF kernel choice needs a comparator.**
- Stated: Raval prefers low-degree polynomial KPCA to RBF, for global fit and few parameters (§3). They give no RBF numbers, and their reason concerns steering. They fit on 1,500-2,000 activations and say kernel methods need large, diverse data (§8, D.1).
- Stated: Gurnee reports dilation, wider fields at larger counts (§2.1).
- Inference: at n=800, add held-out polynomial KPCA with p=1, 2, 3 as a nested series, since p=1 recovers PCA. A stationary RBF kernel may fit dilation badly. Use a known-curvature sweep to calibrate the detector, as Raval §4 does. This is CPU work.

**G. Same-text reading may leave very little to measure.**
- Stated: when Gemma 2 27B base read instruct rollouts, same-role vectors had cosine above 0.99 between base and instruct (Lu B.3). This is the closest published analogue of our design. It covers one model, and the paper does not state the text format.
- Inference: raw clouds may look almost identical across stages, and a large shared mean can drive that cosine. Centre per checkpoint, and set the smallest effect worth reporting before the run.
- Stated: DPO adds a mean shift of relative size 0.151 and 0.250 (Raina Table S12). Inference: per-checkpoint fits remove this shift, while pooled or base-anchored fits keep it.

**H. Do not assume a steady rise.**
- Stated: DPO alone moves the chart little (overlap 0.939), SFT moves it more (0.745), and SFT then DPO does not return to Base (Wang Table 2). Base to instruct rank is not monotone across behaviours (Wang Tables 9, 11).
- Stated: effects depend on objective and architecture (Sinha §4, §5).
- Inference: this is a weak prior against a rise at each stage. Wang's DPO and SFT runs differ in learning rate and steps, so objective and update size are confounded. Pre-register the stage contrasts, not only a trend.

**I. Fixed text does not fix meaning.**
- Stated: direction meaning flips with context (Lampinen §3-4). A manifold can vanish from top PCs on generic prompts (Berdnikov D.4). Persona geometry changes by task (Xiao §3.1).
- Stated: base models were left out of Xiao because failed role-play would confound results. Moskvoretskii attributes an SFT rise to "easier extraction", which they call likely.
- Inference: reading fixed text removes generation differences. It does not show that base and RL checkpoints treat the role the same way. Any result holds for that text, which supports the second text source row.

**J. Text floor and format control.**
- Stated: format alone can produce the structure (Cacioli §4.2), and co-occurrence reproduces concept geometry (Nava §5). Karkada (in `LITERATURE.md`) agrees.
- Inference: this strengthens the text floor row. Add role-name shuffles or format-matched roles if the cells allow it.

**K. Claim presence, not use.**
- Stated: Qwen uses linear number directions despite curved geometry (Hindupur §4). GPT-2 has circles with trivial task accuracy (Engels). Peak-geometry layers can be weakly causal (Cacioli §4.3).
- Inference: a positive result in this test says the cloud has that shape. It says nothing on whether the model uses it. This supports S12's "out of scope; say so".

**L. Pooling needs a second check.**
- Stated: mean pooling gave d about 1.9, last token about 0 (Vasilenko §3.7). That is a weak single-author study, and reader notes flag statistical problems.
- Stated: the RL residual is "not a fixed offset" (Li §4.1).
- Inference: mean-pooled replies can hide or create structure. If a stored second pooling exists, report it. If not, state this as a limit.

**M. Metric stays open.**
- Stated: Euclidean is not privileged in the final layer (Park 2024 §3, D.2). Most RL hidden-state energy sits in directions the head barely reads (Li §5.4, one pair).
- Inference: unit RMS scaling does not settle this. Whitening keeps flatness but changes RBF distances. Report one robustness run in a second metric.

Retries extract over the existing staging directory, so files absent from the next transfer survive.

**4. Should fix · verified — correct quote states can fail G4**

[gates.py:172](/Users/brendon/persona-manifolds/manifold-persona/experiments/q1_emergence/261029_base_role_vs_format/gates.py:172)

Centred cosine is undefined when stored quote vectors have zero centred norm.  
**Case:** a clean CPU run with two identical story quotes passes whole-reply reconstruction but fails quote reconstruction with NaN cosines.  
Rounding alone also triggers this: `[1.00001, 2.00001]` and `[1.00002, 2.00002]` both become `[1, 2]` in float16.  
**Fix:** handle zero or rounding-scale centred norms explicitly, using a storage-error comparison before declaring reconstruction failure.

**5. Should fix · verified — the blank-line fix broadens the approved colon rule**

[gen_extract.py:110](/Users/brendon/persona-manifolds/manifold-persona/experiments/q1_emergence/261029_base_role_vs_format/gen_extract.py:110)

The approved offline rule ignores ASCII spaces after a colon; the new code also ignores tabs.  
**Case:** `" say:\t\n\nJUNK"` previously cuts to `" say:"`; the new code retains `JUNK`.  
All 1,600 saved canary rows still match the offline cut, so this regression lies outside those saved cases.  
**Fix:** preserve the approved colon exception while supporting whitespace inside blank lines, or explicitly revise the rule.

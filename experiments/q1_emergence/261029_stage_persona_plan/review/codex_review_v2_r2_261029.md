**2. [TEXT] Filtering bootstrap draws can manufacture a positive change. R4's floor fix is wrong.**

Evidence: C:51 applies the reliability floor inside each bootstrap draw.
C:81 explicitly reports normalized values only in draws where both stages pass that floor.
C:82 builds the change interval from those draws; C:70 uses paired normalized differences for decisions.
C:36 also says floors apply to the 95% lower bound, leaving two different floor procedures.

Failing case: of 2,000 paired draws, 1,200 have reliability 0.49 and transition difference −0.20.
The other 800 have reliability 0.70 and difference +0.10.
The unfiltered interval is [−0.20, +0.10]; retaining only passing draws gives [+0.10, +0.10].
The retained-draw p-value becomes zero, despite most draws supporting a negative difference.

Exact fix: calculate each checkpoint's reliability lower bound from all paired draws, before interpreting a normalized comparison.
If either bound fails 0.5, report the normalized comparison as unavailable, with raw results beside it.
Otherwise retain every paired draw for its interval and p-value.
If a draw has an undefined denominator, report the normalized interval as unavailable; never silently delete that draw.

This retains the accepted reliability floor and paired comparison.
It removes selection on the same random values used to claim a change.
Apply one rule to C:51, C:69–70 and C:81–82.

**3. [TEXT] The new stage-change reading can declare change when the complete role maps are identical.**

Evidence: C:81–82 defines change as `1 − r_norm` and permits values below zero.
C:83 calls any interval excluding zero evidence that maps differ beyond their split-half noise.
C:71 also says the correction prevents noise from looking like map differences.
Neither statement supplies assumptions under which this normalization estimates noise-free map agreement.

Failing case: create role vectors `S` and wording effects `E`, each 20 × 32, from NumPy RNG seed 31.
At stage A use `S + 0.2*k[w]*E`; at stage B use `S − 0.2*k[w]*E`.
Use `k = [−3, −3, 2, 2, 2]`, with identical rows across questions and replicates.
Both complete, equally weighted role maps are exactly the map of `S`, because the five wording effects average to zero.

I used the 50 wording halves generated by N:74–83 and the centred cosine/Spearman statistic at N:62–71.

The normalized agreement was 1.256678, so reported change was −0.256678.
A 2,000-draw role bootstrap gave change interval [−0.410454, −0.174571], with both reliability lower bounds above 0.69.

Question resampling has no effect in this example. No bootstrap draw was removed.
The role bootstrap used E:368–389's distinct-role centring and repeated-pair weights.
Thus C:83 declares a map difference although the complete role maps are identical.
Checkpoint-specific wording sensitivity causes the result; this is not independent sampling noise removed by the formula.

Exact fix: retain the owner's report-only measure, but remove C:83's noise-adjusted inference.
Describe the number as a normalized cross-half comparison, conditional on the fixed wording panel.
An interval wholly below zero flags a normalization problem; it must not establish map change.
Remove the guarantee at C:71 and add this equal-map, unequal-wording-sensitivity case to G5 (C:46).

A formal claim of change beyond noise needs a separately specified and calibrated test.
The current report-only owner decision does not require that claim (D:112; C:79).

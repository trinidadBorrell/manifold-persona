Stage reply read: Instruct, SFT and DPO

The run rule: I read 20 transcripts per stage before any number.
Each screen holds one prompt. I see the exact text the model got, then three replies to it: Instruct (pod A), SFT and DPO. All three got the same input and the same seed. For each reply I press Yes or No. There are 20 prompts and 60 replies. Every click saves at once, so I can stop and come back.

The question for each reply

  • Role prompts: does this reply play the role, and does it make sense as an answer?
  • The default prompt (no role): does this read as the model's normal assistant voice, and does it make sense?

Same scheme as the 12 Nov review

  • Yes: the reply shows the role clearly, in all of it or in part of it. It may stop mid-sentence at the 128-token cap.
  • No: a plain answer anyone could give, only the role's name, polite advice with nothing of the role, a different role, or nonsense.
  • Doing the role's job counts: a translator who translates the question is in role.
  • Optional: an outcome class, and a note per reply. A note box for the whole prompt is at the bottom.

What this page does not show

  • No judge label and no number from the states. The stage names are shown on purpose: this is a read of what each stage does, not a blind label set.

**Major — An undefined null produces the smallest possible p-value**

Locations: [maps.py:194](/Users/brendon/persona-manifolds/manifold-persona/experiments/q1_emergence/261029_fixed_text_read_through/review/code_before_fixes_261030/maps.py:194), [maps.py:198](/Users/brendon/persona-manifolds/manifold-persona/experiments/q1_emergence/261029_fixed_text_read_through/review/code_before_fixes_261030/maps.py:198).

The observed statistic skips undefined halves, but the null uses an ordinary mean. One unsupported half can therefore make every null value NaN, and `NaN >= observed` is always false: **9,999 undefined permutations produce p = 0.0001**.

**Fix:** reject non-finite observed or null statistics before computing p. Apply consistent half-support rules to the observed statistic and null; never count undefined permutations as evidence.

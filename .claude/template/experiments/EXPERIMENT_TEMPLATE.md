# Experiment note — blank template, not a result

Copy this note into `experiments/<topic>/<YYMMDD_name>/` for a new run. Replace prompts with actual facts. Mark missing details as missing. Do not treat this example as a completed experiment.

## Question

What will this test teach?

## Expected result

What do you expect? What result would change the next decision?

## Cheapest test

Can a cheaper test answer the question? Would one model and one dataset help?

## Mode and reason

Choose de-risk or extended. Give one reason. A short notebook is enough for a de-risk test.

## Model and data

Record exact names, versions, splits, paths, and the prompt or prompt path.

## Code and command

Record the code path, version or commit ID, and exact command. State if no run happened.

## Config and seed

Record settings, config path, and random seed. Mark fields that do not apply.

## Raw output paths

Link actual raw output files or state that none exists. Keep raw data and results out of Git.
If files are remote, record the store or dataset ID, exact revision, and file path.

## Examples and errors

Inspect raw examples and errors before summary scores. Record patterns and limits.

## Contrary evidence

Record opposing cases, failed checks, and checks that were not done.

## Next decision

State what the test taught and the next test or stop decision. Record needed feedback.

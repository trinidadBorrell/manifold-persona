# Project research instructions

Replace this heading and add the project's question, model and data conventions, cost limits, and owners before work starts. Keep project facts in this file and `research/PLAN.md`.

Read `research/PLAN.md` and `research/EXPERIMENT_INDEX.md` before a new test. Use `.claude/skills/research-cycle/SKILL.md` to choose de-risk or extended mode, record the run, and set the next decision.

Before an external empirical claim, use `.claude/skills/challenge-result/SKILL.md`. Link every number to an actual source file. State missing checks and contrary evidence. An agent review is not an independent human review. Neither a file nor a hook proves a scientific claim true.

Keep local settings, secrets, data, and raw results out of Git. Review `.gitignore` when the project adds new storage paths.
For remote artifacts, mirror the dated experiment path and record the exact store version and file path. Keep old files with unknown run details under a labeled legacy path. Check a remote copy before any local removal.
